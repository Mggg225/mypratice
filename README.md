# Git 练习项目

这个仓库用于练习 Git 常用指令。

## 包含的文件

- `hello.py` — 一个简单的 Python 脚本
- `notes.txt` — 随手记笔记用

## 常用指令速查

```bash
git status                 # 查看工作区状态
git add <file>             # 把文件加入暂存区
git commit -m "说明"       # 提交
git log --oneline          # 查看提交历史
git branch <name>          # 新建分支
git checkout <name>        # 切换分支
git merge <name>           # 合并分支
```
